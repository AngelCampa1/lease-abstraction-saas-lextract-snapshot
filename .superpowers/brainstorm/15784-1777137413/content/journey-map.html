End-to-End User Journey — Lextract.io

Every step a first-time user takes, from landing to export

Stage What happens Pain points
1. Upload page /upload
Lands on page with hero, dropzone, and sample CTA. Drops their PDF. Sees upload progress bar.
LOW Both CTAs (Upload + Sample) compete equally — the primary action isn't clear
LOW No sense of what comes next — "what do I get for $20?"
2. Processing /processing/{id}
Watches step progress (Upload → Extract → Score → Done). Waits 30s–3min depending on page count. Sees notification prompt.
HIGH If user closes tab, they lose the anonymous session — results are gone
MED No email capture — user can't "come back later"
LOW Browser notification opt-in feels intrusive as first interaction
3. Teaser view /results/{id}
Sees 5 fields visible, rest blurred. Sees red flag count. Sees confidence chart. Hits a CTA to unlock.
HIGH Anonymous user must sign up before they can even see payment — two gates, not one
MED Blurred fields don't show which categories are locked — low FOMO value
MED Red flag count shown but no hint of what the flags are — users may not understand urgency
4. Signup gate /signup?return=…
Anonymous user is forced to create an account (email + password) before proceeding to payment.
HIGH Hard stop — user already invested time, now faces a wall before getting value
HIGH No "why do I need an account?" explanation
MED Email verification step (if required) adds another round-trip
5. Stripe checkout stripe.com
Redirected to Stripe-hosted checkout. Enters card details. Submits. Redirected back to /results.
MED Leaves the app — breaks immersion and raises trust questions
LOW No "what happens after I pay?" — uncertainty about next step
6. Full results /results/{id}
Sees 14-category accordion with all 126 fields. Red flag panel. Confidence scores. Edit + export options. CamAudit banner.
HIGH 126 fields in 14 categories — no "where do I start?" guidance
MED Inline editing is not discoverable — user doesn't know they can click fields
MED Export is async — user requests file, waits for a job, then downloads
7. Dashboard /dashboard
After first extraction: sees quick stats, extraction history, credit balance. For new users: welcome banner + empty state.
LOW Credit balance is shown but there's no clear path to buy more
LOW Welcome banner appears only before first extraction — no guided first-run experience
