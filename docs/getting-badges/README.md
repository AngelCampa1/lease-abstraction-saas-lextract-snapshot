# Lextract Directory Submission Kit

This folder packages the copy, requirements, assets, and QA notes needed to submit Lextract to SaaSHub, AlternativeTo, Product Hunt, G2, and BetaList.

Use this order:

1. SaaSHub
2. AlternativeTo
3. G2
4. BetaList
5. Product Hunt

SaaSHub and AlternativeTo are lower-friction directory listings. G2 should start early because reviews take time. BetaList works best while Lextract still reads as new or recently launched. Product Hunt should be treated as the launch moment, not a casual directory submission.

## Hard Blockers

- Product must stay live at `https://lextract.io`.
- Pricing, terms, and privacy pages must stay reachable:
  - `https://lextract.io/pricing`
  - `https://lextract.io/terms`
  - `https://lextract.io/privacy`
- The upload flow must be reachable from the submitted URL.
- Use a domain email for verification where possible: `angel.campa@lextract.io`.
- Do not claim legal, tax, accounting, or guaranteed accuracy outcomes.
- Do not use the same long description on every platform.

## Owner Checklist

- [ ] Confirm `https://lextract.io` loads in a private browser.
- [ ] Confirm upload, pricing, sample report, terms, and privacy pages load.
- [ ] Pick the screenshots from [assets-checklist.md](./assets-checklist.md).
- [ ] Create or confirm accounts for each platform.
- [ ] Submit each listing using its platform file.
- [ ] Save submitted URLs and moderation status in the platform file.
- [ ] When a listing goes live, add the live listing URL and check backlink behavior.

## Source Policy

Each platform file cites the official source used for requirements where available. AlternativeTo does not publish a complete current public submission spec, so its file uses AlternativeTo's own account/contribution and app-page documentation, plus the fields visible in current AlternativeTo app pages.
