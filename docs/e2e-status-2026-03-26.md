## Auth fixes landed this session

| Commit | Fix |
|--------|-----|
| `bb1f170` | Post-signup race: 600ms retry on `get-session` (superseded) |
| `8215477` | **Root fix**: switch `getAuthHeaders()` to `/api/auth/token` — bypasses SDK's 5-min session cache that stripped the `set-auth-jwt` header |

Root cause: the Neon Auth SDK caches `get-session` responses in a signed cookie for 5 minutes. Cached responses are plain JSON with no headers, so `set-auth-jwt` was never present → 401s on all backend calls for the entire TTL window after every login/signup.

## Known issues / watch list

- **Sentry error reporting endpoint** hits 403 in browser console — unrelated to app logic, Sentry DSN config issue
- **`trusted_origins` in Neon Auth** required manual `updated_at` touch to reload config; should be stable now but monitor if auth 403s recur after compute cold starts
- **Stale HttpOnly auth cookies** in Playwright's persistent profile cause `INVALID_ORIGIN` 403 on auth endpoints — always `clearCookies()` before each test session
- **Stripe is in live mode** — checkout sessions have `cs_live_` prefix; test cards (`4242...`) are rejected. Switch `STRIPE_SECRET_KEY` to `sk_test_...` in Railway env to enable test card payments
- **Location/Glossary slug format** — `/locations/los-angeles` 404s; correct slug is `/locations/los-angeles-commercial-lease-abstraction`. Same pattern for glossary (no `cam-cap` entry — use full term slugs like `tenant-improvement-allowance`)
- **`POST /payments/use-credit` CORS failure** — OPTIONS preflight returns 405 with no `Access-Control-Allow-Origin` header; `CORSMiddleware` is not intercepting the preflight in production. Root cause: `RateLimitMiddleware` (a `BaseHTTPMiddleware` subclass) runs before `CORSMiddleware` in the stack — this is a known Starlette compatibility issue where `BaseHTTPMiddleware` wrapping can prevent pure-ASGI `CORSMiddleware` from intercepting OPTIONS. Fix: move `CORSMiddleware` to be the outermost middleware (add it last, after `RateLimitMiddleware` and `CorrelationIdMiddleware`), or switch rate limiter to a pure-ASGI implementation.
