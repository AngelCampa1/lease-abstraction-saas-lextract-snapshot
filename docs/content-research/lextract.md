## Internal linking and risk controls

### Internal linking map

Build the site around a clear **TOFU → MOFU → BOFU → lead magnet / trial** flow.

**Core money pages** should anchor everything: homepage, pricing, sample report, lease abstraction software, lease extraction software, and the new pay-per-lease / due diligence / integration pages. Those pages should receive links from every comparison page, workflow page, and lead-magnet landing page.

**Topical hubs** should become true parent nodes:
- fields → child field pages → relevant clause pages → relevant workflows → product page  
- clauses → child clause pages → relevant red-flag pages → industry / lease-type pages → product page  
- workflows → system pages / diligence pages → lead magnets → pricing  
- integrations → PDF-to-system pages → API / pricing / sample report  
- templates → lead magnets → workflows → core product pages  
- glossary / lease-types / industries / locations / states → MOFU pages, then BOFU pages

**Recommended link patterns**
- Every **field page** should link to at least one clause page, one workflow page, one lead magnet, and one product page.
- Every **clause page** should link to the corresponding field page, red-flag page, industry page, and attorney-focused BOFU page.
- Every **workflow page** should link to the relevant system integration page, template/workbook, sample report, and pricing.
- Every **comparison/alternative page** should link to pricing, sample report, the relevant workflow page, and at least one supporting case study.
- Every **lead-magnet page** should link to one adjacent workflow page and one adjacent product page in the post-form thank-you experience.

### Open questions and limitations
